# Screenshot provenance and upload status

All originals in `web-preview` were captured from the running Expo web app, not generated UI. A temporary development fixture supplied a fictional profile with W1D1 completed. It is removed from the final source. No real child data used. Some QA captures contain developer overlays or viewport artifacts and must not be uploaded.

`iphone-candidates` exports are 1290×2796 opaque JPEG. `google-play-candidates` exports are 1080×1920 opaque JPEG. They preserve the original app image with cream padding where aspect ratios differ; they are upscaled web review candidates, not native high-resolution captures. Only export after matching each scene against the release build and replacing source captures with native resolution images. Do not submit the QA paywall (preview prices/sandbox label).

Suggested order: meet Capy → first prayer → illustrated story → pond rewards → puzzle selection → Memory Pond. No numerical engagement/learning claims or reviews were fabricated.

Required final captures:
- iPhone 6.9-inch accepted dimensions, e.g. 1290×2796 or 1320×2868.
- iPad 13-inch supported because supportsTablet=true, e.g. 2064×2752 or 2048×2732.
- Android phone: 1080×1920, 4 or more gameplay screenshots; consider real tablet captures as well.
- No alpha, status-bar privacy leaks, developer notices, loading screens, paid-only features presented as free, or stretched UI.

Sources: https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications/ and https://support.google.com/googleplay/android-developer/answer/9866151
